Anand Linux for Termux

Anand Linux is an Anand-branded Linux environment for Android using Termux and PRoot.

Installation

1. Update Termux
```
pkg update && pkg upgrade -y
```
2. Install Git
```
pkg install -y git
```
4. Clone repository
```
git clone https://github.com/AnandDevAI/anand-linux.git
```
4. Open folder
```
cd ~/anand-linux
```
5. Run installer
```
chmod +x *
```
```
./anand-theme.sh
```

Start Anand Linux
```
./start-anand.sh
```
Red Terminal Prompt

┌──(Anand㉿Linux)-[~]
└─#

Features

- Red Kali-style prompt
- Termux + PRoot
- No rooted phone required
